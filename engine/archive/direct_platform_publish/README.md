# Publicacao direta (arquivado)

Implementacao original de `clipador-publish`, que publicava clipes direto em YouTube (Data API v3 OAuth), Instagram (Content Publishing API) e TikTok (Content Posting API), cada uma com seu proprio fluxo OAuth e token local.

Arquivado em 2026-09-01: substituido por integracao via Buffer (https://buffer.com) como intermediario unico para as 3 plataformas, decisao do usuario. Codigo preservado aqui apenas como historico, nao e mais usado nem importado pelo `clipador.publish`.
